# study-content

学習コンテンツを管理するリポジトリです。ルートの `index.html` が各コンテンツへの入口です。

## コンテンツ

- [01_なぜから学ぶ G検定](01_なぜから学ぶ%20G検定/README.md)：AIの全体像、機械学習の3方式、モデル評価を学ぶ教材。メニューのリンク先は `01_なぜから学ぶ G検定/app/` です。

## 一覧ページを確認する

リポジトリ直下でHTTPサーバーを起動します。

```powershell
py -3 -m http.server 8042 --bind 127.0.0.1
```

`http://127.0.0.1:8042/` を開いてください。一覧ページはHTML・CSS・ローカルSVGだけで動き、ビルドや外部サービスは不要です。PWA教材のオフライン機能にはHTTPのlocalhostまたはHTTPSが必要です。

## コンテンツを追加する

1. `02_コンテンツ名` などのフォルダを作り、ブラウザで開けるHTMLまたは静的ビルド成果物を用意します。
2. 内容に合ったSVGまたはPNGのアイコンを `assets/icons/` に保存します。
3. `index.html` の `<article class="content-card">` を複製します。`href` を起動先に、画像の `src` をアイコンに変更し、番号・カテゴリ・タイトル・説明・特徴を書き換えます。
4. 一覧ページからリンク先が開くことと、スマートフォン幅での表示を確認します。

リンク例：`02_コンテンツ名/index.html`。フォルダ内でHTMLを直接配信する場合は `02_コンテンツ名/` でも構いません。Reactなどの教材はソース用のindex.htmlではなく、配信用にビルドしたフォルダへリンクしてください。教材一覧は静的HTMLのため、フォルダの追加だけでは自動登録されません。

画像には文字を詰め込みすぎず、内容を表す構図を使います。カードには見出しがあるためアイコンのaltは空にしています。カードを追加すると一覧は自動で折り返します。

## 教材の開発

```powershell
cd "01_なぜから学ぶ G検定"
npm run dev
```

詳しい操作・ビルド・テスト方法は、プロジェクト内のREADMEを参照してください。G検定教材を更新した場合は、メニューのリンク先を更新するため `npm run build:menu` も実行します。
