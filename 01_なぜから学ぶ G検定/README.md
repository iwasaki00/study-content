# WHY LEARN G / なぜから学ぶ G検定

v0.2.2 — 第7話L009「AIは写真のどこを見ているの？」を追加。第6話L008「AIはどうやって間違いから学ぶの？」を追加。第5話L007「AIはどうやって猫と犬を見分けるの？」を追加。第0章から、機械学習の基礎編（工場の4話）とディープラーニング編（動物保護施設）へ進める、ブラウザ内完結の学習アプリです。L003「機械学習の3つの方法」、L004「モデル評価」、L005「どの箱で確かめるか」、L006「利用条件の違い・データの偏りと公平性」、L007「写真とディープラーニング」、L008「間違いから学ぶ」、L009「画像とCNNの計算」を収録。G検定全範囲を網羅するものではなく、公式教材・公式試験問題ではありません。

## 起動

Node.js 22.12以降（検証環境 Node.js 25.9.0）、npmを使用します。

```sh
npm ci
npm run dev
```

開発URLはターミナルに表示されます。PWAの確認には本番ビルドを使用してください。

```sh
npm run build
npm run preview -- --port 4173
```

ブラウザで http://127.0.0.1:4173/ を開きます。ビルド成果物は `dist/`。公開・デプロイは実施していません。

## 第0章から始める

新規ホーム「3分で全体像を見る」→第0章の4項目を読む→「第1話で、AIの学び方を試す」。途中の「もう少し詳しく」は任意です。G検定の範囲、ルールと事例の違い、層を重ねる意味をアプリ内で読め、閉じると元の項目・位置へ戻ります。

AI ⊃ 機械学習 ⊃ ディープラーニングを入れ子の図で示し、見本箱・カメラ・損傷の違いをローカルのドット絵PNGで説明します。第0章は解放条件ではなく、ホーム・コースからいつでも開けます。学習中の主ボタンは直近の話の「続きから学ぶ」です。「最初から学ぶ」も同じ話に対応します。

L003・L004の「第0章で用語を確認」→「第0章を閉じて戻る」で、元の場面・操作・スクロール位置を保ちます。第0章の閲覧は学習記録を書き換えません。

## 第1話の操作

第0章「第1話で、AIの学び方を試す」→3コマ漫画→「仕分け台へ行く」→「最初の箱を流す」→「検査済みの箱を見本に加える」→「搬送の様子を見る」→「似た搬送記録をまとめる」→「別の搬送経路を試す」→「2つの運び方を比べる」→必要なら「早く届ける／箱を丁寧に運ぶ」を切り替える→「出荷を見届ける」→3方式を振り返り「ここで終える」。試験問題・専門知識・詳細設定なしで完了できます。

- 主な目的は、検査を終えた箱を16時の集荷へ運ぶこと。実時間の制限はありません。
- 本編は、答え付きの別の見本追加（最近傍分類）→答えのない搬送記録の整理（K-means）→同じ2経路の報酬比較（概念デモ）の順です。変化を見てから名前を説明します。経路の比較は、方策を学習した結果ではありません。
- 各結果の「仕組みを詳しく見る」で、距離計算・散布図・クラスタ数・反復・行動ごとの点数を確認できます。出荷後は詳細教材・比較・知識マップも任意で開けます。「出荷の物語に戻る」で本編の保存状態へ戻れます。
- 最後の「試験問題で確認する」、またはメインの「演習」から既存12問と48選択肢の解説へ進めます。問題への回答は完了の条件ではありません。
- 「ここで終える」で完了を記録してホームへ戻ります。「最初から学ぶ」は今回のL003体験だけを初期化し、回答・過去の完了・復習候補・設定を保持します。
- 「続きから学ぶ」は漫画の読書位置、見本追加、グループ分け、条件切替、結末を復元します。旧版の進行は既存の場面から再開し、新しい物語へ強制移動しません。全編を体験する場合は「最初から学ぶ」を選べます。
- 「記録」で復習候補・履歴・JSON書出し／統合／置換を利用できます。既存の復習機能は変更していません。

## 第4話 L006を学ぶ

「コース」→L006「第4話を始める」→「2つのラインで試してみる」→全体18/20、明るい10/10、暗い8/10と不良品2箱の見逃し→「何が違うのか調べる」→照明条件の違いを見る→「照明を見直してみる」→「暗いラインの照明を調整する」→同じD09・D10の判定が変わり10/10へ→「用意したデータを振り返る」→「人に関わるAIの判断も考える」→「第4話をまとめる」→「ここで終える」。第3話の結末「第4話を開く」からも開始できます。

- 学習用の明るい条件のデータからしきい値を求め、照明係数を変えて箱ごとに実判定・集計します。画像認識モデルを動かす実験ではありません。
- 工場の技術的な性能差と、採用などで人に影響する公平性の検討を分けます。照明改善による性能保証や、社会的公平性の証明とは扱いません。
- 「G検定の問題で確認する」は正誤の全選択肢解説があるオリジナル4問。「もっと詳しく学ぶ」は5つの深掘り、計算方法、出典です。どちらも任意です。
- 第4話も独立した再開・やり直し・履歴・完了・JSON復元に対応。第0章の関連項目から同じ場面へ戻れます。
- 本文と4点の新規ドット絵はローカル配信・オフライン対応です。

## 第3話 L005を学ぶ

## 第2話 L004を学ぶ

「コース」→L004「第2話を始める」→「100箱を流す」→見逃しの発見→「別の仕分け設定で試す」→A/B比較→「見るべき数字を振り返る」→「試験での呼び方」→「ここで終える」。任意の3問は「試験問題で確認する」から選べます。第1話の結末にある「第2話を開く」からも進めます。自動では移動しません。

- 同じ100箱に対する固定の判定データから、一致数・見逃し・止めすぎ・正解率・再現率を集計します。学習用の見本へ箱や人の検査結果を追加しません。
- 第2話も「続きから学ぶ」「最初から学ぶ」に対応し、操作はL003の進行と12問の回答を変更しません。L003のやり直しでもL004の進行・3問の履歴を保持します。
- 正解率・再現率は結果後に説明し、混同行列は任意の「詳しく見る」に配置します。Bを候補にする理由と、止まった良品を人が再確認することを示します。
- 「記録」で両レッスンの完了、L004の回答履歴、合計回答数を確認できます。L004の回答はL003と別に保存し、JSON書出し・統合・置換にも含まれます。

IndexedDBの保存完了後に「端末に保存済み」と表示します。失敗時は再試行してください。保存失敗時も画面上の記録をJSONへ書き出せます。ブラウザのデータ消去・容量制限などによって記録が失われる場合があり、定期的なバックアップを推奨します。

初回オンライン時、本番ビルドのアプリ・教材資産をService Workerが取得します。「オフライン教材：準備済み」になってからオフライン利用してください。外部の公式参照リンクはオンライン接続が必要です。PWAはHTTPSまたはlocalhostで利用してください。iPhoneからPCのHTTP LANアドレスを開く場合、Service Workerが利用できないことがあります。

## 第5話 L007を学ぶ

第0章の包含関係の図にある「第5話で、写真と層の仕組みを見る」、コースの「ディープラーニング編」、または第4話の結末から開けます。前の話の閲覧は必須ではありません。

「写真を見てみる」→写真をタップして見た目の手がかりを見る→「ほかの写真も見てみる」→「AIには写真がどう見えている？」→「拡大する」→画素をタップ、または方向ボタンで色を観察→「写真の情報が進む先を見る」→「1ステップ進む」を4回→「どうやって特徴を学ぶの？」→必要なら「学習時の流れ／利用時の流れ」を切り替える→「写真以外の使い道も見る」→「施設での体験をまとめる」→「ここで終える」。

- 本編は7場面。数式・事前クイズ・RGB値の暗記は不要です。最後に5問の演習、5項目の深掘りを任意で選べます。
- 画素はローカルPNGをCanvasで縮小した実データです。任意のCNN実験は同じ画像の8×8の明るさに固定3×3フィルタを適用する実計算です。
- 層の流れと学習／利用の図は概念デモです。ニューラルネットワークの訓練・猫犬の推論は実行しません。
- 第5話の再開・やり直し・回答履歴は他の4話と独立。形式1のバックアップとオフライン配信を維持します。
- [v0.2.0の実装報告](docs/IMPLEMENTATION_REPORT_v0.2.0.md)に画像・画面・検証結果を記載しています。

## 第6話 L008を学ぶ

第5話の結末、コース一覧、第0章の関連説明から開始できます。「間違いの理由を調べる」→「予測と正解を見比べる」→「内部の数字を調整してみる」→「1回学習する」→「何度も学習してみる」→1/10/50回の学習を試す→猫C01の判定が変わったら「新しい動物でも試す」→「学習に使っていない4例を確かめる」→まとめ→「ここで終える」。

2入力・中間層3・1出力の小規模ネットワークを実際に学習させます。Sigmoid、二値交差エントロピー、全8例の平均勾配、学習率1.0。画像認識モデルではなく、人が設定した架空の2特徴のデモです。更新・グラフ・判定・再開は実計算に基づきます。確認用4例を重みの更新に混ぜません。

「最初からやり直す」は実験の重みと履歴を初期値に戻し、物語の練習場面に残ります。コース／ホームの「最初から学ぶ」は第6話の導入から新しいセッションを開始します。どちらも他の話・過去の回答・完了記録を消しません。保存履歴の容量を抑えるため1セッション1000更新まで。自動学習はなく、ボタンの回数分だけ更新します。

[実装報告](docs/IMPLEMENTATION_REPORT_v0.2.1.md)に計算値・勾配検証・画像・テスト結果を記載します。

## 第7話の操作（v0.2.2）

第0章「第7話で、画像とフィルタを動かす」（またはコース／第6話の結末）→「写真を拡大する」→「小さなフィルタを重ねる」→枠をタップ／「前へ」「次へ」→「別のフィルタも試す」→A/B/Cを切り替える→「特徴マップを小さくまとめる」→「フィルタ結果を見る」→「ReLU結果を見る」→「プーリング結果を見る」→「全体の流れを見る」→「第7話をまとめる」→「ここで終える」。画像・フィルタの変更、計算式、演習、深掘りは任意です。

- 実際の16×16の猫・犬PNGをCanvasで読み込みます。透明部分は白と合成し、RGBの加重和を255で割って明るさ0〜1へ変換します。
- 反転なし3×3演算（相互相関）、歩幅1、パディングなしで14×14。ReLU後、2×2・歩幅2の最大値プーリングで7×7を計算します。符号付き表示用の色変換は元の値を変更しません。
- 固定フィルタを使う概念デモです。猫犬の分類モデルを学習・実行しているわけではなく、特徴マップだけで判断根拠が完全に分かるとも説明しません。
- 第7話の画像・フィルタ・位置・処理段階・深掘り・演習を保存します。「最初から学ぶ」は第7話のみ初期化し、過去の回答・完了記録と第0〜6話の状態を維持します。
- 自動送りは任意で一時停止でき、再開時には停止しています。「動きを減らす」設定では自動送りを省略します。オフラインには本番ビルドの初回取得完了が必要です。
