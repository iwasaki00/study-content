## 3. 第5話の全操作手順

1. 新規ホーム「3分で全体像を見る」で第0章を開く。
2. AI・機械学習・ディープラーニングの入れ子図の下にある「第5話で、写真と層の仕組みを見る」を押す。コースの「ディープラーニング編」→「第5話を始める」、または第4話の結末からも開ける。前の話の読了は不要。
3. 施設のスタッフの困りごとを読み、「写真を見てみる」。
4. 猫または犬の写真をタップし、複数の見た目の手がかりを確認。「ほかの写真も見てみる」で垂れ耳の猫・立ち耳の犬・顔の一部が隠れた猫を見る。採点はない。
5. 「AIには写真がどう見えている？」→「拡大する」。同じ猫の画素をタップするか、上下左右ボタンで色を観察。RGB値の説明は開かなくてよい。
6. 「写真の情報が進む先を見る」→「1ステップ進む」を4回。入力画像→入力データ→中間層1→中間層2→出力まで、現在地と説明が変わる。「自動で流れを見る」は任意で、一時停止できる。
7. 「どうやって特徴を学ぶの？」で、写真と正解による学習の流れを見る。「利用時の流れ」で、新しい写真から予測して人が確認する図へ切り替えられる。
8. 「写真以外の使い道も見る」で画像・音声・文章・生成の4用途を見る。
9. 「施設での体験をまとめる」で結末と重要事項を振り返り、「ここで終える」で完了を保存。演習・深掘りを開かなくても完了する。

途中終了後は、ホームの直近教材またはコースの「続きから学ぶ」で保存した場面と操作状態に戻る。「最初から学ぶ」はL007の現在の体験だけを初期化する。

## 7. インタラクティブ教材の実装

写真：同じ素材の写真枠に個別のタップ対象を置き、選択した写真の手がかりを文字で表示。採点や正解選択ではない。

画素：ローカルPNGをCanvasで32×32へ縮小してRGBAを読み取り、その配列を表示用Canvasへ書き込む。選択座標から同じ配列の色を取り出し、色見本と任意のRGB値を表示する。タップ・方向ボタン・矢印キーで操作でき、座標も保存する。

層：0〜4の現在地からノード・矢印・説明を表示する。「1ステップ進む」と任意の自動表示を用意。自動表示は停止可能で、第0章への移動・画面非表示・場面移動で停止する。再開時は勝手に再生しない。動きの少ない表示設定にも対応。

学習／利用：別々の説明図を切り替える。利用時には正解ラベルを入力しないこと、人が予測を確認することを示す。切替状態も保存する。

## 8. 概念デモと実計算の区別

| 項目               | 実行している内容                                                                  |
| ------------------ | --------------------------------------------------------------------------------- |
| 画素拡大           | 実画像の読み取り・縮小・色の取得                                                  |
| CNNの任意デモ      | 同じPNGを8×8の明るさにし、固定3×3フィルタを実計算。端の追加なし・移動幅1、出力6×6 |
| 層の段階表示       | 情報の流れを説明する模式図。猫・犬の推論計算ではない                              |
| 学習時・利用時の図 | 概念図。ニューラルネットワークを訓練していない                                    |
| 結末               | スタッフが仕組みを理解して手作業を続ける。自動分類の達成を主張しない              |

フィルタは左右の変化を見る固定値と平均の固定値。学習済みとは表示しない。深層学習の「畳み込み」で一般に使う、フィルタを反転しない相互相関を計算する。結果はデータから生成し、数値一覧で色に頼らず確認できる。ブラウザテストでは別に画像から計算した値と照合した。

## 9. 深掘り5項目

D01「なぜ生まれた？」、D02「層と重み」、D03「活性化関数」、D04「誤差逆伝播法」、D05「CNN」を実装。各項目は、やさしい説明→具体例→図解→技術説明→関連知識IDと出典の順。閉じると開く前の項目・位置へ戻る。

D01の1943年の研究は史実として原論文の公開資料を参照し、施設の架空の物語と区別した。D04では勾配計算と最適化による重み更新を区別。D05に実計算を用意した。各層の担当部位を決め付けず、深いほど必ず良いとも説明していない。
