# 解説改善記録・次版候補 — v0.5.0

全64問を維持。Q01は操作練習、通常問題は63問です。v0.4.0の重点８問に加え、旧計画の残り55問から以下の12問を改善しました。盤面・選択肢の図形・正解ID・難易度・ruleFamilyは変更していません。

## 改善した12問

| ID | 選定理由・改善前 | v0.5.0の改善 |
|---|---|---|
| Q03 | 切り欠きと穴を同時に見てしまいやすい | 切り欠き→穴→統合の名称と順序。穴を回さない既存アニメーションを維持し、一致した特徴を✓、不一致を×で図示 |

| Q39 | 移動説明が静止した並び中心 | 反転状態を固定して位置だけ動かす専用表示。鏡の形と枠の位置を個別照合 |
| Q40 | 共通部分と逆向き回転を混同しやすい | AND→反時計回り90°を表示。回転省略・OR・逆方向の選択肢を区別 |
| Q43 | 回転・反転の交互操作を静止比較 | 既知の例を左90°回転、直前の形を左右反転する動き。非対称な角と鏡の形を分離 |
| Q56 | ３入力ANDの途中結果が省かれていた | 入力１ AND 入力２→途中結果 AND 入力３を上段・下段それぞれ表示。３段階から５段階へ |
| Q57 | 先に回す対象と合成順を追いにくい | ２番目だけ回す→ORの途中図と動き。根拠のない誤答原因の断定を削除 |
| Q58 | 合成と条件抽出の関係が見えにくい | OR後に中央段だけ残す帯と、対象外の印が消える動き。静止時も抽出結果を表示 |
| Q62 | 循環移動を静止図で追う必要があった | OR→印を右へ１マス。右端の印は消え、左端に現れる。reduced-motionでは移動後に固定 |
| Q63 | 位置・向き・塗りが同時に変化 | 位置だけの移動、旗だけの回転、塗り比較、統合の順。枠と旗を一緒に回さない |
| Q64 | AND・回転・移動の多段処理が難しい | 各処理の途中図、回転・循環移動の動き、７段階の短い名称。根拠のない誤答理由を修正 |

12問すべてに規則名・適用順・特徴別の一致／不一致・解答後の図形比較を追加。「似た考え方の問題へ」は既存ruleFamilyを使い、異なる見た目を優先します。同じruleFamilyの別問がない場合は、その旨を表示します。回答前には比較結果や正解図形を出しません。

Q43・Q56・Q57・Q58・Q62・Q63・Q64の題名は、規則を先に教えない短い名称に変更しました。Q57d・Q64a/dなど、選択図形から誤答原因を一意に言えないものは分析上「分類できない誤答」です。解説文の単語から推測して分類しません。
