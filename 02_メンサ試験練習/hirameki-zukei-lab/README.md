# ひらめき図形ラボ v0.0.1

図形の規則を見つける、非公式の練習アプリ。オリジナルの３問で「解く → 見る場所を確かめる → 別の問題で試す」を体験します。

## 起動

`index.html` をブラウザで直接開けます。ビルド・インストール・外部通信は不要です。

HTTPで確認する場合、このフォルダで次を実行します（Node.js使用）。

```powershell
node serve.cjs
```

PCで <http://127.0.0.1:8043/> を開きます。停止は Ctrl+C。

iPhone実機で確認するときは `node serve.cjs --lan` を実行し、同じWi-Fi上のiPhone Safariから `http://PCのLAN内IPv4アドレス:8043/` を開きます。必要に応じてOSのファイアウォール設定を確認してください。実機での表示・長押し・連打・ピンチズーム・動きを減らす設定は未確認です。

GitHub Pagesに既存の方法で配置すれば、リポジトリURLの下の `02_メンサ試験練習/hirameki-zukei-lab/` から開けます。アセットはすべて相対参照です。今回commit・push・公開はしていません。

## 追加したファイル

- `index.html`：起動画面と読み込み先
- `style.css`：320pxからの表示、SVGの強調・回転、動きを減らす設定
- `questions.js`：ID・盤面・選択肢・正解ID・ヒント・解説を持つ３問のデータ
- `shapes.js`：矢印・点・輪・穴のSVGと読み上げラベル
- `app.js`：選択・採点・ヒント・解説・結果・再スタート
- `serve.cjs`：任意のローカル確認用静的サーバー
- `verify.cjs`：Playwrightによる操作・表示・問題データ検証
- `screenshots/`：Q02の問題画面と解説画面（Chromium／WebKit、390×844）
- `README.md`：起動・構成・検証記録

既存の他教材・親メニューは変更していません。変更ファイルはUTF-8、LFです。履歴保存・途中再開・タイマー・自動生成はありません。

## 検証記録（2026-11-15）

Playwrightのモバイル設定でChromium 148.0.7778.96、WebKit 26.4を確認。iPhone実機のSafariでの検証ではありません。

- Q01～Q03の盤面・選択肢・正解（3番／2番／4番）と解説を照合。輪の外側だけが回り、穴は回らない描画構造を確認。
- Q02の誤答３択、Q03の「向きのみ正しい／個数のみ正しい／どちらも異なる」のフィードバックを照合。
- 未選択では確定不可、選択変更、確定の連打防止、採点後の選択ロックを確認。
- ヒントの２段階の強調、ヒント中に欠けた図形が表示されないことを確認。正解の選択肢への印は採点後だけ。
- 解説の前へ・次へ・再生、最後の解説まで次問を無効化、３問完了、再スタートを確認。
- 結果はQ02・Q03だけを表示。自力正解・ヒントを使った正解・解説で確認の３区分と、Q03のヒントなし正解を確認。
- 320px／390pxで横スクロールなし、全図形が横幅内に収まることを確認。390×844で盤面と４択が同時に表示されることを確認。
- `prefers-reduced-motion: reduce` で回転アニメーションなし。強調・回転後の静止画・短文を確認。
- JavaScript構文チェック、実行時エラーなし、LFを確認。

検証の再実行には別途Playwrightと対応するChromium／WebKitが必要です。アプリ本体の依存ではありません。

```powershell
# 通常はPlaywrightを利用できる環境で
node verify.cjs

# 既存のPlaywright環境を使う場合
$env:PLAYWRIGHT_PATH = 'C:/path/to/node_modules/playwright-core'
node verify.cjs
```

## 問題を増やす場合

`questions.js` の配列へ同じ形式のデータを追加すると、進捗・４択・ヒント・段階解説・結果表示は問題数に追従します。新しい図形の種類は `shapes.js`、新しい規則の解説表示は `app.js` の `demo()` に追加してください。Q02／Q03固有の誤答文は `feedback()` にあります。問題追加時は、各問題に対応するフィードバックと検証も追加します。
