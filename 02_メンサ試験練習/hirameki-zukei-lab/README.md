# ひらめき図形ラボ v0.1.0

図形の規則を見つける、非公式の練習アプリ。固定のオリジナル24問で「解く → 見る場所を確かめる → 別の問題で試す」を繰り返します。実試験の再現、公式ロゴ、IQ換算、合格見込みの表示はありません。

## 作業場所と起動

実際の更新先は `study-content/02_メンサ試験練習/hirameki-zukei-lab/` です。v0.0.1の場所と親メニューのリンクを維持しました。確認した作業フォルダと親階層には `AGENTS.md` はありませんでした。他教材・親メニューは今回変更していません。commit・push・公開もしていません。

このフォルダで次を実行し、PCで <http://127.0.0.1:8043/> を開きます。停止は Ctrl+C。

```powershell
node serve.cjs
```

iPhone実機では `node serve.cjs --lan` で起動し、同じWi-Fi上のSafariから `http://PCのLAN内IPv4アドレス:8043/` を開きます。必要に応じてOSのファイアウォール設定を確認してください。

ビルド・外部ライブラリ・CDN・サーバーAPIは不要です。アセットは相対パスです。GitHub Pagesのリポジトリ配下から配信できます。HTMLを直接開くこともできますが、端末内の保存はブラウザのファイルURLの扱いに依存します。継続して記録する場合は同じHTTP/HTTPSのURLで利用してください。ポートが変わると別の保存領域になります。

## 練習の流れ

- 初回はQ01をすぐ表示します。「あとで練習する」でメニューへ移動できます。Q01〜Q03のチュートリアルはいつでもやり直せます。
- **毎日５問**：日本時間の日付でセットを固定します。未回答を優先し、その中で分野を分散します。不足分は最後に出た日時が古い問題から補います。同じセット内の重複はありません。
- 開始時と回答確定時に保存します。同日の再読み込みでは自動で未回答の問題から再開します。５問確定後は結果を再表示します。メニューへ戻っても同日の問題・順序は固定です。
- 開いたまま日付をまたいでも、進行中のセットは開始日のままです。次にメニューから「毎日５問」に入ると、新しい日本時間の日付でセットを用意します。
- **じっくり練習**：分野を選んで時間制限なしで練習します。その分野の未回答を先に、既回答は最後に出た日時が古い順に出します。Q01は含みません。
- **苦手の復習**：不正解と、ヒントを使って正解した問題が対象です。各対象の `ruleFamily` が一致する未回答の別問題を優先し、なければ元の問題を出します。画面に元の問題IDと出題する類題IDを表示します。
- 復習でヒントなし正解すると、紐づいた元の対象を完了します。ヒント利用や誤答では残します。復習で解いた類題を同じ元項目として重ねて登録しません。元問題IDをキーにして二重登録を防ぎます。
- **学習記録**：初見の「ヒントなし正解／ヒントあり正解／不正解」を固定して保持します。解き直しても上書きしません。Q01は出題・集計対象外で、Q02〜Q24の23問を集計します。
- 回答は選択後に「答え合わせ」で確定します。解説の「前へ／次へ／もう一度見る」と、「次の問題」は別操作です。最後の解説まで確認すると次問へ進めます。

保存は `localStorage` の `hirameki-zukei-lab:v1` に行います。初見結果、最終回答、回答回数、復習対象、日付別５問と回答、直近の出題日時、初回体験済みフラグを保持します。外部へ送信しません。保存が拒否・容量超過などで失敗した場合は画面に案内し、メモリ内で練習を続けます。その場合、ページを閉じた後の記録維持はできません。保存領域を消すと記録も消えます。v0.0.1は記録を保存していなかったため移行対象データはありません。

## 24問の一覧

難易度は１（基本）〜３（複合・発展）。正解は固定の選択肢番号です。４分野それぞれ６問ですが、回転・反転のQ01は操作練習専用です。

| Q02 | 複数ルール | 矢印の向き＋点の数 | 2 | 2 | independent-orientation-count |
| Q03 | 複数ルール | 切り欠きの向き＋穴の数 | 2 | 4 | independent-orientation-count |
| Q04 | 回転・反転 | 90°反時計回り | 1 | 2 | rotate-ccw-90 |
| Q05 | 回転・反転 | 180°回転 | 1 | 3 | rotate-180 |

| Q08 | 回転・反転 | 90°時計回りと左右反転が交互 | 3 | 3 | alternate-rotate-mirror |
| Q09 | 移動・個数 | 右へ１マスずつ移動 | 1 | 4 | move-linear |

| Q15 | 重ね合わせ | どちらかにある印を残す・丸 | 2 | 3 | overlay-union |

Q04〜Q08・Q22・Q23は斜めの角と短い出っ張りを持つ非対称の図形です。320pxで見比べたうえで、回転と反転の違いがはっきりする形に調整しました。Q08は６個の観測例、Q11とQ14は５個の観測例を示します。連続パターンには読む順を表す番号を付け、行をまたぐ際も順序を明確にしました。Q15〜Q20・Q24はすべての行に「共通の位置」「左にしかない位置」「中央にしかない位置」を含めています。

## 構成・変更ファイル

- `app.js`（更新）：初回体験、メニュー、練習セッション、採点、段階解説、復習、学習記録、結果画面。

- `verify.cjs`（更新）：全検証の入口。
- `verify-data.cjs`（追加）：出題・描画とは独立した座標・数列・ビット演算による検算、保存・出題ロジックのテスト。

## 検証方法

問題データと学習ロジックの検証はNode.jsだけで実行できます。

```powershell
node verify-data.cjs
```

ブラウザを含む全検証には別途Playwrightと、そのバージョンに対応するChromium／WebKitが必要です。アプリ本体の依存ではありません。

```powershell
node verify.cjs

# 既存のPlaywright環境を使う場合
$env:PLAYWRIGHT_PATH = 'C:/path/to/node_modules/playwright-core'
node verify.cjs
```

### 検証記録（2026-11-20）

データ・ロジック検証、Chromium 148.0.7778.96／WebKit 26.4でのブラウザ検証がすべて通りました。Windows上のPlaywrightによるモバイル設定です。iPhone実機Safariの検証ではありません。

- 24問の連番ID、分野ごとの６問、通常対象23問、異なる４択、正解ID、難易度、ヒント、段階解説、誤答別の短文を照合。
- 描画コードとは別に、旗の頂点を座標変換して回転／反転を検算。回転・反転５種類と交互変化を全観測例に照合し、意図した規則だけが当てはまることを確認。
- 移動・個数はすべての観測例と次の値を照合。Q14は増分１〜５を確認。重ね合わせは独立した９ビット演算で全行を計算し、和／共通部分／排他的和を取り違えても他の選択肢が正解にならないことを確認。
- Q02・Q03・Q21〜Q23は縦と横の特徴を独立に照合。Q24は集合演算と90°回転を別々に計算して全３行を照合。
- ５問の重複なし、初回セットの４分野分散、同日固定・再読み込み、JST翌日の更新、日付をまたぐ進行中セットの固定を確認。
- 未回答が２問しかない状態で２問とも含む５問を作り、全問既回答時は出題日時が古い順で補うことを確認。
- Q02誤答後は未回答のQ22を優先。類題をすべて回答済みにするとQ02に戻ること、復習のヒントあり正解では対象を残し、ヒントなし正解で完了すること、初見結果を上書きしないこと、二重登録しないことを確認。
- 保存拒否・書き込み失敗・不正なセットデータでも、練習と５問の出題を継続できることを確認。
- 両ブラウザの320px／390pxで、全24問の盤面・４択・全解説段階の横スクロールなし・図形の見切れなしを確認。390×844では全問の盤面と４択が採点前の同じ画面内に収まります。
- 全24問で未選択確定の防止、選択変更、確定連打の防止、ヒント２段階、ヒントによる欠けた図形の非表示、採点後の選択ロック、解説の前へ・次へ・再生を確認。
- 両ブラウザで全69通りの誤答フィードバックを表示して照合。Q02・Q03は既存の特徴別フィードバック、Q01〜Q03の通し操作と再スタートも回帰確認。
- 毎日５問をブラウザで完走し、確定後の再読み込みで次の未回答へ自動再開、同日結果の再表示、JST23:59→00:01のセット維持とメニュー再入場時の更新を確認。
- Q02の不正解からQ22の復習へ進み、ヒントありでは対象を残し、類題がなくなった場合はQ02へ戻ること、ヒントなし正解で対象を完了すること、初見の不正解記録を維持することをブラウザでも確認。
- `prefers-reduced-motion: reduce` で重ね合わせと回転のアニメーションを止め、静止画と短文を表示。Q03の反時計回りも停止するように、既存CSSの優先順位を修正しました。内側の穴を回さないことも確認。
- 保存領域にアクセスできないブラウザ環境で案内を表示し、チュートリアルから毎日５問まで進めることを確認。
- JavaScript全10ファイルの構文、LF、`git diff --check`、既存の `node serve.cjs` によるHTMLと全モジュールのHTTP応答を確認。親メニュー・共通CSS・親README・共通アセットの差分はありません。

### 未確認事項

iPhone実機Safari、VoiceOverによる読み上げ、GitHub Pagesでの実配信は未確認です。ブラウザのモバイル設定と実機検証は異なります。長押しメニュー、ダブルタップ拡大の抑制、ピンチズームの維持、iOSの保存容量・プライベートブラウズでの挙動は実機確認が残っています。ページのviewportで最大倍率を制限していません。

有限の図形列には複雑な後付け規則を作ることができます。ここでは出題する基本規則と、自然な競合候補（左右の回転・反転、一定量／交互の変化、和／共通部分／排他的和）を観測例に照合して見直しています。利用者による難易度・解説の理解しやすさの評価はこれからです。
